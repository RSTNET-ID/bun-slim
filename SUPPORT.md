# Support

Bun Slim adalah open-source starter dan tidak memiliki SLA support.

Gunakan GitHub Issues untuk:

- bug yang dapat direproduksi;
- regression;
- dokumentasi yang salah atau tidak lengkap;
- usulan perubahan yang memiliki use case konkret.

Sebelum membuka issue:

1. pastikan masalah masih terjadi pada branch terbaru yang relevan;
2. jalankan `bun run doctor` atau `bun run doctor:offline` bila sesuai;
3. sertakan versi Bun, branch, database, langkah reproduksi, expected behavior, dan actual behavior;
4. hapus credential, token, URL yang mengandung password, payload sensitif, dan data pelanggan dari log.

Security vulnerability mengikuti `SECURITY.md`, bukan public issue.
